Что умеет утилита:

    Live Packet Sniffing — перехват TCP и UDP пакетов в реальном времени через сетевой адаптер в Promiscuous режиме.

    Маппинг приложений — автоматически определяет, какой именно процесс (Discord, Chrome, Telegram и т.д.) отправляет или принимает пакет.

    Параллельный Ping-монитор — измеряет задержку до выбранного IP/домена (по умолчанию 8.8.8.8) в фоновом потоке и выводит пинг рядом с каждым пакетом.

    Умный фильтр адаптеров — отсекает виртуальные интерфейсы (VPN, VMware, TAP, Radmin) и подключается к реальной сетевой карте (Wi-Fi / Ethernet).

    Auto-UAC Elevation — запрашивает права администратора при запуске для доступа к низкоуровневому трафику.

    CLI UI — ASCII логотип, кастомный progress bar и цветная подсветка протоколов, IP-адресов и портов.

Как запустить:

    Убедитесь, что в системе установлен Npcap или WinPcap.

    Скомпилируйте проект (dotnet publish -c Release).

    Запустите .exe от имени администратора.
