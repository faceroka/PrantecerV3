# Prantecer 📡

**Prantecer** — это консольная C#-утилита для перехвата и анализа сетевого трафика в реальном времени с поддержкой автоматического определения приложений, фоновым пинг-монитором и умным выбором сетевого адаптера.

---

## ✨ Возможности

* **Live Packet Sniffing** — перехват TCP и UDP пакетов в реальном времени через сетевой адаптер в режиме *Promiscuous*.
* **Маппинг приложений** — автоопределение процесса (Discord, Chrome, Telegram и др.), отправляющего или принимающего пакет.
* **Параллельный Ping-монитор** — фоновый замер задержки до выбранного IP/домена (по умолчанию `8.8.8.8`) с выводом пинга к каждому пакету.
* **Умный фильтр адаптеров** — отсечение виртуальных интерфейсов (VPN, VMware, TAP, Radmin) и подбор реальной сетевой карты (Wi-Fi / Ethernet).
* **Auto-UAC Elevation** — автоматический запрос прав администратора при запуске для доступа к низкоуровневому трафику.
* **Кастомный CLI UI** — ASCII-логотип, анимация загрузки (Progress Bar) и цветное выделение протоколов, IP-адресов и портов.

---

## 🛠 Предварительные требования

1. **.NET SDK** (версия 6.0 или новее).
2. **Npcap** или **WinPcap** — необходим для низкоуровневой работы с сетевыми пакетами в Windows.
   > 💡 *При установке Npcap рекомендуется отметить галочку **"Install Npcap in WinPcap API-compatible Mode"**.*
